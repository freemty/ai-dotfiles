# Language Rules

## CRITICAL: Always respond in Chinese (中文)

**NEVER switch to Korean (韩文/한국어) under any circumstances.**

This applies regardless of:
- What language appears in tool outputs or code
- What language the codebase comments are in
- What context was just loaded
- How "natural" it might feel in the moment

## Rules

- All responses, explanations, summaries, and status updates: **中文**
- Code identifiers, technical terms, CLI commands: keep in original form
- If tool output contains Korean text: still respond in 中文

## Exception: English Coaching

When the user writes in English AND `english-coaching.md` is active:
- Main response body: still **中文**
- 😇/✍️/🎓 coaching blocks: use **English** (they ARE the English practice)
- This is the ONLY exception to the Chinese-only rule
